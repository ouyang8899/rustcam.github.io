RustCam

产品特性

RustCam 的完整能力清单：实时视频、设备接入、云台控制、流媒体集群、电子地图、录像回放、告警与权限。

视频服务

实时播放、多画面布局、录像回放

  • ▸flv.js / hls.js / video.js 多协议播放
  • ▸单画面与多画面布局切换
  • ▸录像回放与时间轴检索
  • ▸实时会话状态可见

设备管理

发现、注册、状态监控与分组

  • ▸GB28181 SIP 注册与设备接入
  • ▸ONVIF WS-Discovery 设备发现
  • ▸设备分组与行政区划
  • ▸通道级在线状态监控

云台控制

PTZ 协议支持与预置位管理

  • ▸GB28181 与 ONVIF 双协议控制
  • ▸ContinuousMove / AbsoluteMove
  • ▸预置位增删改查
  • ▸设备离线返回 503 并自动重注册

媒体服务器

集群部署与统一适配

  • ▸主流媒体服务器完整支持
  • ▸多厂商媒体服务器适配
  • ▸按权重调度与启停控制
  • ▸Hook 事件回调处理

电子地图

地图渲染、设备标记与状态筛选

  • ▸MapLibre GL JS 渲染
  • ▸GeoServer 图层与 WFS 代理
  • ▸设备点位聚合
  • ▸地图选点绑定通道坐标

录像与回放

录像任务、策略与文件管理

  • ▸录像任务启停、暂停与恢复
  • ▸按时间段录像策略
  • ▸录像文件与播放地址
  • ▸多通道并行回放

告警

告警上报、记录与处理闭环

  • ▸外部告警上报接口
  • ▸告警记录查询与分页
  • ▸处理状态标记
  • ▸告警与会话联动

移动眼

无人机作为会动的视点接入同一套平台

  • ▸MAVLink / PX4 / ArduPilot 自动识别
  • ▸Cesium 3D 地球与实时位置姿态
  • ▸起飞、降落、返航、定点、云台、相机指令与 ACK
  • ▸航线规划与顺序执行
  • ▸禁飞区 / 允许区与越界告警
  • ▸多摄像头设备关联：一架无人机可挂接多个平台摄像头
  • ▸关联后通道实时解析，直播页自动取 FLV / HLS 地址
  • ▸控制权租约、审计与状态持久化

用户与权限

JWT 认证与 RBAC 权限控制

  • ▸JWT 登录与令牌刷新
  • ▸Casbin 策略授权
  • ▸用户 / 角色 / 权限三级模型
  • ▸动态角色权限分配
