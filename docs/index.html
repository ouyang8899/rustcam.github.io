RustCam

开发者

RustCam 的环境要求、目录结构、快速开始、配置说明、API 概览与常见问题。

Environment

Rust

1.88+

PostgreSQL

14+

Redis

6+

Node.js

18+（前端构建）

项目结构

crates/rustcam-media/Rust 后端库：api / application / auth / domain / infrastructure / protocol / transport / drone_gateway
crates/rustcam-server/服务端可执行程序（rustcam-media）
crates/rustcam-drone-service/移动眼控制面：注册表、遥测影子、控制权、指令、围栏、审计
crates/rustcam-drone-adapter/机载适配：MAVLink / PX4 / ArduPilot 接入
crates/rustcam-drone-sim/MAVLink 机体模拟器（测试/演示）
frontend/Vue 3 控制台（Vite + Element Plus + Pinia + Cesium）
testenv/移动眼一键测试环境（start.ps1 / stop.ps1 / 截图）
clientapp/Qt 桌面客户端（CMake + FFmpeg）
public/对外文档：api.md、architecture.mmd、architecture.png
sql/数据库脚本（schema.sql）

快速开始

初始化数据库

bash
psql -U postgres -c "CREATE DATABASE rustcam;"
psql -U postgres -d rustcam -f sql/schema.sql

启动后端

bash
cargo run
# 或发布构建
cargo build --release
./target/release/rustcam-media

启动 Web 控制台

bash
cd frontend
npm install
npm run dev

一键移动眼测试环境（无需真实飞控）

powershell
pwsh -File testenv\start.ps1
# 登录：admin / admin123
# 内置 MAVLink 模拟器：PX4 / ArduPilot

登录并获取令牌

bash
curl -s -X POST http://127.0.0.1:8081/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"admin123"}'

配置文件

编辑仓库根目录的 config.toml。生产环境务必修改 JWT secret 与数据库口令。

toml
[server]
host = "0.0.0.0"
port = 8081
tls_enabled = false

[database]
url = "postgres://user:pass@localhost:5432/rustcam"
max_connections = 10

[redis]
url = "redis://localhost:6379"
pool_size = 5

[drone]
service_addr = "http://127.0.0.1:50051"

[[media_servers.servers]]
name = "zlmediakit"
url = "http://127.0.0.1:80"
api_key = "your_api_key"
server_type = "zlmediakit"   # zlmediakit / srs / xiu
weight = 100
enabled = true
server_tag = "default"

[jwt]
secret = "change-me-in-production"

API 概览

后端基于 Axum 暴露 HTTP + WebSocket 接口，业务接口统一前缀 /api/v1，共 120 条受保护路由与 15 条公开路由（含移动眼 19 条）。

认证方式

除公开端点外，所有接口都需在请求头携带 JWT：Authorization: Bearer <access_token>

http
Authorization: Bearer <access_token>

常见问题

支持哪些设备接入方式？

GB28181（SIP 注册）、ONVIF（WS-Discovery 发现）、RTSP 直连以及 WebSocket 接入，统一抽象为设备与通道模型。

云台控制设备离线时返回什么？

GB28181 设备离线时返回 503，适配器会自动重新注册设备。

是否支持 HTTPS？

支持。在 config.toml 中配置 tls_enabled、tls_cert 与 tls_key，由 rustls 实现 HTTPS 与 WSS。

语音对讲如何实现？

媒体侧通过 MediaNode 中间件链完成 G711 ⇄ PCM 转换与重采样，支撑 GB28181 广播与 ONVIF Backchannel 语音对讲。

没有无人机硬件可以体验移动眼吗？

可以。仓库内置 rustcam-drone-sim，可模拟 PX4 / ArduPilot 心跳、遥测与指令 ACK；执行 pwsh -File testenv\start.ps1 即可拉起模拟器、适配器、控制面、主服务与前端。

移动眼支持哪些飞控？

通过 MAVLink 支持 PX4 与 ArduPilot，按 HEARTBEAT.autopilot 自动识别；连接方式支持 UDP / TCP / 串口。

其他媒体服务器什么时候可用？

媒体服务器适配层已抽象完毕，部分实现仍在推进，详见产品特性页的模块进度表。
