RustCam

About

RustCam-Media is a modern video surveillance gateway and signalling control platform: a Rust backend handling protocol ingestion, media forwarding and signalling control, a Vue web console, and a Qt client for desktop operations. Released under the MIT licence.

Architecture principles

Layers, not a pile

HTTP handlers → application services → domain model and ports → infrastructure; business rules never depend on a protocol or a database.

Ports and adapters

SignalAdapter unifies GB28181 / ONVIF / RTSP / WebSocket; MediaServerAdapter targets media servers.

Media separated from signalling

The transport and media planes handle SIP signalling and RTP, with a MediaNode middleware chain performing audio conversion and resampling.

Secure by default

JWT + Casbin guard every business endpoint, TLS is implemented with rustls, so HTTPS and WSS work out of the box.

Roadmap

Done

Full GB28181 chain

SIP signalling, PS stream parsing, PTZ, platform broadcast and two-way talk are all complete.

Done

ONVIF discovery and control

WS-Discovery probing, ContinuousMove / AbsoluteMove and Backchannel talk are complete.

Done

RTSP and media servers

RTSP ingestion and the media server cluster are complete, with the hook event chain wired up.

In progress

Media server adapters

The adapter layer is finished; some integrations are still partially implemented.

Done

Mobile Eye

Drones join the surveillance domain as moving vantage points: PX4 / ArduPilot flight control, a Cesium 3D live view, camera device association with automatic live streams, routes, geofences, control leases and audit are delivered, with a built-in MAVLink simulator for testing.

Next

Continuous evolution

Video wall layouts, recording policies and map pickers keep iterating.

Contribute

The development environment, local startup, code style, commit conventions and the PR flow are described in CONTRIBUTING.md. Before submitting, run at least:

bash
cargo fmt && cargo clippy --all-targets -- -D warnings && cargo test

Commit messages follow Conventional Commits, for example: feat(frontend): 通道编辑弹窗接入地图选点。
