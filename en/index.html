Protocols & media stack

Signalling is unified behind one adapter; video is served by mature streaming servers.

GB28181

SIP registration, INVITE calls, PS stream parsing, platform broadcast and two-way talk

ONVIF

WS-Discovery discovery, ContinuousMove/AbsoluteMove PTZ, Backchannel audio

RTSP

TCP / UDP modes, including direct RTP over RTSP pull

WebSocket

Real-time event push and two-way talk channel, JWT protected

MAVLink

Drone flight-control integration (PX4 / ArduPilot) over UDP / TCP / serial, with command acknowledgements

MOBILE EYE

Fixed cameras watch what matters; the mobile eye watches what moves.

A drone is not "a camera that flies": it carries its own flight control and decides where to look, how to look and when to return. RustCam pulls that flight capability into the surveillance domain — live position on a Cesium 3D globe, route planning, geofences and flight commands share the same recording, evidence chain and video wall as fixed cameras.

No new fixed points

Dispatch only when it is needed: no cabling, no poles, no permanent points, and coverage that grows on demand instead of being buried in advance.

No scenario lock-in

Routes, geofences and alarm rules are composed by configuration; patrol, blind-spot coverage and emergency response are templates of one capability set.

  • MAVLink / PX4 / ArduPilot
  • Cesium 3D live view
  • Route planning & execution
  • Geofences & breach alarms
  • Camera association & auto play
  • Control leases & preemption
  • Flight logs & audit
  • Built-in MAVLink simulator

Architecture

Clear layers, clean abstractions

Axum + Tokio layering: HTTP handlers → application services → domain model and ports → infrastructure. Signalling goes through SignalAdapter, media through MediaServerAdapter.

SignalAdapter

GB28181 / ONVIF / RTSP / WebSocket share a single port; adding a protocol does not touch the business layer.

MediaNode middleware chain

Handles G711 ⇄ PCM conversion and resampling for GB28181 broadcast and ONVIF Backchannel talk.

MediaServerAdapter

One media server interface targets any media server, so clustered deployment needs no business changes.

Quick start

Up in three steps

Clone the repository, prepare dependencies, start the service.

1

Clone the repository

bash
git clone https://gitee.com/ouliuying/rustcam.git
cd rustcam
2

Prepare database and cache

bash
psql -U postgres -c "CREATE DATABASE rustcam;"
psql -U postgres -d rustcam -f sql/schema.sql
3

Build and run

bash
cargo build --release
./target/release/rustcam-media

Start the web console

bash
cd frontend
npm install
npm run dev

The desktop client is a Qt 5/6 CMake project. See the developer docs for the full setup.
