RustCam

Features

The full RustCam capability list: live video, device ingestion, PTZ control, streaming clusters, electronic map, recording playback, alarms and access control.

Video services

Live playback, multi-view layouts and recording playback

  • ▸flv.js / hls.js / video.js playback
  • ▸Single and multi-view layouts
  • ▸Recording playback with timeline search
  • ▸Visible live session state

Device management

Discovery, registration, status and grouping

  • ▸GB28181 SIP registration
  • ▸ONVIF WS-Discovery
  • ▸Device groups and admin regions
  • ▸Per-channel online status

PTZ control

PTZ protocol support and preset management

  • ▸GB28181 and ONVIF control
  • ▸ContinuousMove / AbsoluteMove
  • ▸Full preset CRUD
  • ▸Returns 503 when offline and re-registers

Media servers

Clustered deployment with a unified adapter

  • ▸Full support for mainstream media servers
  • ▸Multi-vendor media server adapters
  • ▸Weighted routing and enable/disable
  • ▸Hook event handling

Electronic map

Map rendering, device markers and status filters

  • ▸MapLibre GL JS rendering
  • ▸GeoServer layers with WFS proxy
  • ▸Marker clustering
  • ▸Pick coordinates on the map

Recording & playback

Tasks, policies and file management

  • ▸Start, stop, pause and resume tasks
  • ▸Time-window recording policies
  • ▸Recording files and play URLs
  • ▸Parallel multi-channel playback

Alarms

Reporting, records and closed-loop handling

  • ▸External alarm intake API
  • ▸Query and paginate alarm records
  • ▸Processing status flags
  • ▸Alarm to session linkage

Mobile Eye

Drones join the platform as moving vantage points

  • ▸Automatic MAVLink / PX4 / ArduPilot detection
  • ▸Cesium 3D globe with live position and attitude
  • ▸Takeoff, landing, RTL, goto, gimbal and camera commands with ACK
  • ▸Route planning and sequential execution
  • ▸No-fly / allowed zones with breach alarms
  • ▸Camera device association: one drone can link several platform cameras
  • ▸Channels resolve live once linked; the live view fetches FLV / HLS automatically
  • ▸Control leases, audit and persisted state

Users & permissions

JWT authentication and RBAC

  • ▸JWT login and token refresh
  • ▸Casbin policy authorisation
  • ▸Users / roles / permissions model
  • ▸Dynamic role permission assignment
