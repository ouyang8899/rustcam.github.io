RustCam

应用场景

RustCam 在园区安防、城市治理、工业安防、移动巡检与交通枢纽中的落地方式：痛点、能力映射与收益指标。

园区安防

不同品牌摄像机分散在弱电井与楼层，告警靠人工巡检，事件定位耗时以分钟计。

▸事件定位从分钟级降到秒级；新增设备只需配置地址，无需二次开发。

Capability mapping

  • ·GB28181 / ONVIF / RTSP 统一接入
  • ·电子地图 + 设备点位聚合
  • ·监控墙布局与拖拽编排
  • ·录像策略按区域与时段执行

城市治理

区域级视频资源分散在多个区县平台，跨域调阅需要人工申请，权限边界模糊。

▸跨域调阅流程线上化，权限由策略集中管控，审计有据可查。

Capability mapping

  • ·GB28181 级联接入与平台广播
  • ·用户 / 角色 / 权限三级模型
  • ·JWT + Casbin 细粒度授权
  • ·行政区划与设备分组

工业安防

生产现场与办公区域权限混用，报警事件缺少处理闭环，责任难追溯。

▸告警从「发生」到「处理」全程留痕，事后取证链路完整。

Capability mapping

  • ·告警上报与处理状态标记
  • ·通道级状态监控
  • ·异常录像策略与回放取证
  • ·客户端本地实时预览

移动巡检（移动眼）

固定点位覆盖不到的盲区与临时布防靠人工处理，巡查记录与取证材料散落在纸面和个人设备里。

▸需要时再飞过去看，巡查与取证自动留在平台内，不再产生第二套数据。

Capability mapping

  • ·无人机飞控接入（MAVLink / PX4 / ArduPilot）
  • ·Cesium 3D 地球上的实时位置与姿态
  • ·航线规划、保存与顺序执行
  • ·电子围栏与越界告警阻断
  • ·无人机关联平台摄像头，通道动态解析并自动出流
  • ·控制权租约与飞行日志审计

交通枢纽

高峰时段并发通道数激增，实时流与录像任务争抢带宽，服务质量难以保障。

▸并发能力随流媒体集群线性扩展，单点故障不再中断业务。

Capability mapping

  • ·多服务器权重调度与故障切换
  • ·媒体服务器集群化部署
  • ·TLS 加密传输（HTTPS / WSS）
  • ·TCP / UDP 双传输模式
