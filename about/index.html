RustCam

关于

RustCam-Media 是一个现代化的视频监控网关与信令控制平台：Rust 后端负责协议接入、媒体转发与信令控制，Vue 前端提供 Web 控制台，Qt 客户端面向桌面运维场景。项目以 MIT 协议开源。

架构理念

分层而非堆砌

HTTP 处理器 → 应用服务 → 领域模型与端口 → 基础设施实现，业务规则不依赖具体协议或存储。

端口与适配器

协议侧由 SignalAdapter 统一抽象 GB28181 / ONVIF / RTSP / WebSocket，媒体侧由 MediaServerAdapter 对接媒体服务器。

媒体与信令分离

传输与媒体数据面（transport / media）负责 SIP 信令与 RTP 收发，通过 MediaNode 中间件链完成音频格式转换与重采样。

安全默认开启

JWT + Casbin 贯穿全部业务接口，TLS 由 rustls 实现，HTTPS 与 WSS 开箱可用。

参与贡献

开发环境、本地启动、代码规范、提交规范与 PR 流程详见仓库中的 CONTRIBUTING.md。提交代码前请至少执行以下命令：

bash
cargo fmt && cargo clippy --all-targets -- -D warnings && cargo test

提交信息采用 Conventional Commits 规范，例如 feat(frontend): 通道编辑弹窗接入地图选点。
